成员清单

types.ts: 财务领域共享契约，包含账户、类别、资金来源及软删除审计字段。
api/: HTTP 客户端边界，负责把页面操作映射到 Finance Node API。
FinPageFrame.tsx: 财务路由纯出口，不读取流水；每个财务页面自行加载所需数据和时间范围栏。
pages/: 路由页面；账本页展示已删除流水，设置页/看板细节按 `pages/settings`、`pages/overview` 分组，保留审计可见性。
components/: 可复用业务与基础 UI 组件；业务界面与设计系统活文档消费同一套 ui 原语和主题 token。
lib/: 格式化、分析与页面辅助逻辑；其中资金流分析会把真实账本转换为图表可接受的无环模型。本层所有聚合都以「输入是整本账」为前提，页面必须不传 limit，任何有限数都会在账本增长后变成错误答案。余额类聚合一律经 liveAccounts 排除软删除账户——三个聚合各自 filter 曾让被删账户继续计入净资产，与设置页对同一件事给出两个数。
store/: 跨页面且跨会话记忆的状态（时间区间、看板布局、视角）；持久化值可能与当前账本脱节，读取方负责归一，局部地图见 `store/CLAUDE.md`。

法则: 删除事实由后端保存；界面只能弱化呈现，不能把记录从用户视野中抹去。

[PROTOCOL]: 变更时更新此头部，然后检查 CLAUDE.md
