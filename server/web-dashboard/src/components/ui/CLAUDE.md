成员清单
AlertDialog.tsx: 受控确认与通知弹窗；在对话框内保留异步失败反馈，提交期间拦截 Esc，统一危险操作并禁止业务层退回原生 alert/confirm。
Autocomplete.tsx: 自适应选择器；桌面提供保持当前活动项的可搜索组合框，触屏设备降级为原生 select。
Badge.tsx: 紧凑语义标签；状态色只消费主题 token。
Button.tsx: 按钮原语；统一语义变体、尺寸、图标与加载状态。
Card.tsx: 页面容器原语；统一卡片层级、边框、圆角和内边距。
DatePicker.tsx: 日期选择原语；桌面弹出月历，移动端使用系统日期选择器。
KPICard.tsx: 指标卡原语；承载时间看板的标题、数值、辅助口径与主题强调色。
Modal.tsx: Portal 弹层原语；统一尺寸、滚动锁、Esc 关闭和不卸载表单的错误反馈槽。
NavigationTile.tsx: 导航块原语；Sidebar 消费其选中与悬停状态，财务设计系统页把同一实现当作活文档。
SegmentedSwitch.tsx: 少档位模式开关；财务记账模式与统计毛/纯共享同一交互范式。
Select.tsx: 基础原生选择器封装；保留给无需搜索的简单表单。
StatusPill.tsx: 状态胶囊原语；确保多主题下状态文案对比度一致。
Tabs.tsx: 多面板页签原语；CategoryTabs 统一设置页与业务页的分组导航。
TextInput.tsx: 文本与多行输入原语；统一标签、提示、错误、焦点环和输入边界。
TimelineCanvas.tsx: 时间画布结构与交互视觉原语；在稳定三列骨架上按需扩展引导线通道与细节栏，并统一缩放、标签、时间刻度、分布/事项块及调时手柄。
timeline.css: 日/周时间轴样式真源；集中维护整屏弹性视口、五列等分布局、23px 渐进披露、细节标签/引导线、选中手势和响应式 token，业务层只注入几何、内容与语义色。

法则: 时间与财务两域的业务页面都从这里消费原语与语义 token；两域设计系统页面渲染同一组件作为活文档，不复制外观实现。
财务侧只有 `fin/components/ui/` 中列出的分叉件例外，新增原语一律落在本目录，禁止按域再复制一套。
