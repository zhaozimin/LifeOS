# LifeOS 安装指南

这篇写给完全不懂技术的人。照着做就行，不需要理解为什么。

装完你会得到三样东西：

1. 一个一直在后台跑的小程序（开机自动起来，不会弹窗，不占屏幕）
2. 一个只有你这台电脑能打开的网页面板
3. 一串**访问密钥**，第一次打开面板要用它

---

## 开始之前

### 「终端」是什么

按 `Command + 空格`，输入 `终端`，回车。跳出来一个黑底或白底的窗口，能打字的那个，就是终端。

**本文里所有灰底方块都是命令。** 用法永远是同一套：整段复制 → 粘到终端里 → 按回车 → 等它跑完。跑的过程中屏幕上会滚一些字，那是正常的。

### 先确认电脑上有 Python

把下面这行粘到终端里，回车：

```bash
python3 --version
```

**你会看到**：类似 `Python 3.9.6` 这样一行，数字大于等于 3.9 就行。

**看不到怎么办**：如果它说 `command not found`，或者跳出来一个框问你要不要装「命令行开发者工具」，就点「安装」，等它装完（几分钟），再跑一次上面这行。

## 路径一（推荐）：让 AI 帮你装

如果你已经在用 Claude Code、Codex 这类**能在你电脑上执行命令**的 AI，这条路最省事：你不用碰终端，AI 替你跑。

### 第 1 步：把安装向导交给 AI

把下面这整段复制，发给你的 AI：

```text
请帮我在这台 Mac 上安装 LifeOS，严格按下面的步骤做，不要跳步、不要自己发挥：

1. 打开 https://github.com/zhaozimin/LifeOS/releases/latest ，
   下载名字形如 lifeos-install-skill-1.0.0.zip 的附件，以及它旁边同名的 .sha256 文件。
2. 用 shasum -a 256 -c 校验这个 zip。校验不通过就立刻停下来告诉我，不要继续。
3. 解压，把里面的 lifeos-install 整个文件夹放进你自己的 skills 目录
   （Claude Code 通常是 ~/.claude/skills/，别的 Agent 用你自己的那个）。
4. 执行这一条命令，让脚本自己完成剩下的全部安装：
   python3 ~/.claude/skills/lifeos-install/scripts/lifeos_bootstrap.py install
5. 脚本跑完会打印一行面板地址和一个文件路径。把那一行原样发给我。
6. 中途任何一步报错，把报错原文发给我，不要自己猜着改。
```

**你会看到**：AI 下载、校验、解压、安装，最后给你一行长得像这样的地址：

```text
Dashboard: http://127.0.0.1:59418/dashboard/?token=一长串随机字符
```

**看不到怎么办**：

- AI 说「找不到 Release」→ 说明这个版本还没发布出来。先走路径二或路径三。
- AI 说「校验不通过」→ **不要让它继续**。重新下载一次；还是不通过，说明下载来的文件不对，别装。
- AI 说「目标目录已存在且非空」→ 你以前装过。让它加上 `--upgrade` 重跑，或者先看看旧的那套还在不在（见下面的《装完之后》）。
- AI 自作主张跳过了校验那一步 → 让它重来。这一步是防止你装到被人改过的包。

### 第 2 步：打开面板

见下面《[装完之后](#装完之后)》。

## 路径二：自己下载安装包

不用 AI，自己动手。全程大约五分钟。

### 第 1 步：下载

用浏览器打开：<https://github.com/zhaozimin/LifeOS/releases/latest>

在页面下方的附件列表里，下载这两个文件：

- `lifeos-1.0.0.zip` —— 软件本体
- `lifeos-1.0.0.zip.sha256` —— 校验文件，用来确认下载没出错、也没被人动过手脚

两个都会落进「下载」文件夹。

### 第 2 步：校验下载的包

把下面这两行**一起**粘到终端里，回车：

```bash
cd ~/Downloads
shasum -a 256 -c lifeos-1.0.0.zip.sha256
```

**你会看到**：`lifeos-1.0.0.zip: OK`

**看不到怎么办**：如果它说 `FAILED`，**就到此为止，不要继续安装**。删掉这两个文件重新下载一次。再失败，说明你拿到的包不对。

### 第 3 步：解压，放到安装位置

把下面这三行一起粘到终端里，回车：

```bash
unzip -q ~/Downloads/lifeos-1.0.0.zip -d ~/Downloads
mkdir -p "$HOME/Library/Application Support/LifeOS"
mv ~/Downloads/lifeos-1.0.0 "$HOME/Library/Application Support/LifeOS/app"
```

这就是 LifeOS 的家：`~/Library/Application Support/LifeOS/app`。你的两本账本以后也放在这里面。

**看不到怎么办**：如果最后一行说 `File exists`，说明这个位置已经有东西了——你以前装过。跳到下面的《[已经装过怎么办](#已经装过怎么办)》。

### 第 4 步：装唯一的那个依赖

LifeOS 只需要一个额外的库，用来导出 Excel。把下面两行一起粘到终端里，回车：

```bash
cd "$HOME/Library/Application Support/LifeOS/app"
python3 -m pip install -r server/requirements.txt
```

**你会看到**：一堆下载进度，最后 `Successfully installed openpyxl-...`。

**看不到怎么办**：

- 报错里有 `externally-managed-environment` → 换成这一行再跑一次：

  ```bash
  python3 -m pip install --user -r server/requirements.txt
  ```

- 还是装不上 → **可以先跳过**。缺了它只有「导出 Excel」这一个功能用不了（点了会提示导出不可用），记账和看面板都正常。

### 第 5 步：配置

把下面两行一起粘到终端里，回车：

```bash
cd "$HOME/Library/Application Support/LifeOS/app"
LIFEOS_SETUP_ONLY=1 bash server/install_and_start_lifeos_node.sh
```

**你会看到**：

```text
── LifeOS 已就绪 ──
安装位置：/Users/你的用户名/Library/Application Support/LifeOS/app
Dashboard: http://127.0.0.1:59418/dashboard/?token=一长串随机字符
上面这行地址含访问密钥，只保存在本机 ...../connection-info.txt（权限 0600），不要转发给任何人。
· 已完成配置（LIFEOS_SETUP_ONLY=1），未启动服务；请用 install_launch_agent.sh 安装开机自启。
```

**把那行 `Dashboard:` 记下来**，或者知道它存在哪就行（下一节告诉你怎么再找出来）。

**看不到怎么办**：

- 它说「本机已有一套在服役的 LifeOS」→ 你以前装过。见《[已经装过怎么办](#已经装过怎么办)》。
- 它说「端口 59418 已被一个无法认亲的服务占用」→ 这个端口被别的程序占了。要么关掉那个程序，要么换个端口：在上面那行命令前面加 `LIFEOS_PORT=59419`（下面所有出现 59418 的地方也要跟着换）。

### 第 6 步：让它开机自动运行

把下面这行粘到终端里，回车：

```bash
LIFEOS_INSTALL_PATH="$HOME/Library/Application Support/LifeOS/app" bash "$HOME/Library/Application Support/LifeOS/app/server/install_launch_agent.sh"
```

**你会看到**：两行，长得像这样——

```text
已安装开机自启 com.lifeos.node（解释器 /usr/bin/python3）。
验证：服务应在几秒内监听 127.0.0.1:59418；失败时看 ..../logs/lifeos-node.launchd.err.log。
```

括号里那个路径是**你这台机器上 Python 的实际位置**，跟上面这行不一样很正常。

从此以后每次开机它都会自己起来。你不用再管它。

**看不到怎么办**：

- 它说「缺少 LifeOS runtime/config.json」→ 第 5 步没跑成功，回去重跑第 5 步。
- 它说「找不到可执行的 python3」或「版本低于 3.9」→ 回到《开始之前》把 Python 装好。
- 它说「端口已被无法认亲的服务占用」→ 同第 5 步的处理办法。

### 第 7 步：确认真的装好了

把下面这行粘到终端里，回车：

```bash
python3 "$HOME/Library/Application Support/LifeOS/app/skills/lifeos/scripts/timectl.py" health
```

**你会看到**：一大段 JSON（一堆大括号和引号）。你只需要确认里面**同时**有 `"time"` 和 `"finance"` 两块，各自带一个 `dbPath`，而且这两个路径都在 `.../LifeOS/app/server/runtime/` 下面。

看到这两块，就是真的装好了：一个进程，两本账本，都挂上了。

**看不到怎么办**：

- 只出现一块 → 有一本账本没挂上。把整段输出发给作者或你的 AI，别继续记数据。
- 提示连不上 → 服务没起来。等十秒再跑一次；还不行，重跑第 6 步。

## 路径三：从源码装

适合会用 `git` 的人。

把下面几行一起粘到终端里，回车：

```bash
git clone https://github.com/zhaozimin/LifeOS.git ~/Downloads/LifeOS-src
mkdir -p "$HOME/Library/Application Support/LifeOS"
cp -R ~/Downloads/LifeOS-src "$HOME/Library/Application Support/LifeOS/app"
```

然后**从路径二的第 4 步开始**，一步不差地往下做。

**不需要装 Node.js**：界面是打包好、随源码一起提交的。只有你要改前端源码时才需要 Node。

**注意**：不要把安装目录留在某个 Git 仓库里面。你的账本和访问密钥都在 `server/runtime/` 下，混进版本控制就可能被误提交出去。

## 装完之后

### 打开面板

第一次打开，用那行**带密钥的完整地址**：

```text
http://127.0.0.1:59418/dashboard/?token=一长串随机字符
```

把它粘到浏览器地址栏，回车。

面板打开后，密钥会被存进这个浏览器，同时**自动从地址栏里删掉**。以后你只要访问这个短地址就行：

```text
http://127.0.0.1:59418/dashboard/
```

建议存成书签。

### 密钥丢了怎么找回

密钥一直存在你电脑上的一个文件里。把下面这行粘到终端里，回车：

```bash
cat "$HOME/Library/Application Support/LifeOS/app/server/runtime/connection-info.txt"
```

**你会看到**：那行完整的 `Dashboard:` 地址。

这个文件权限是 0600 —— 同一台电脑上别的账号也读不到。**不要把这行地址发到任何聊天窗口、截图或云笔记里**，它等于你两本账本的钥匙。

### 让 AI 能替你记

把安装目录里的 `skills/lifeos/` 整个文件夹，复制进你的 AI 的 skills 目录（Claude Code 通常是 `~/.claude/skills/`）。走路径一的话这一步 AI 已经替你做完了。

之后你就可以直接说：

> 「我从九点开始写方案，刚写完。」
>
> 「中午吃饭花了 38 块，微信支付。」

AI 会调用 LifeOS 的脚本真正写进账本，然后把写好的那一行念给你听。**没有念出那一行，就不算记上了**——这是这套系统的规矩，AI 不许含糊其辞。

### 已经装过怎么办

你的电脑上只允许有**一套在服役**的 LifeOS。哪一套在服役，写在这个文件里：

```bash
cat ~/.config/lifeos/install.json
```

**你会看到**：`{"installPath": "/Users/你的用户名/Library/Application Support/LifeOS/app"}`

安装脚本发现这个指针指着**别的**目录时会直接拒绝，并把那个目录打印给你看。这是保护你：如果它闷头装下去，你以后每一条记录都会写进新的空账本，而你在原来的面板上什么都不会多出来。

- 想继续用旧的那套 → 别装了，直接打开旧的面板。
- 确实要换成新目录 → 在安装命令前面加 `LIFEOS_REPLACE_POINTER=1`。**旧账本不会被删**，只是不再服役。

### 卸载

把下面两行一起粘到终端里，回车：

```bash
cd "$HOME/Library/Application Support/LifeOS/app"
bash server/uninstall_lifeos.sh
```

它会当面问你一次，输入 `yes` 才动手。

**它会做的**：停掉开机自启、移除全局指针。

**它不会做的**：**不删你的数据**。两本账本、附件、访问密钥都原样留在 `server/runtime/` 里。想连数据一起清掉，只能你自己手动删那个目录——而且删之前请先读《[备份与恢复](备份与恢复.md)》。

## 在手机上看（可选，且尚未验收）

LifeOS 永远只监听 `127.0.0.1`。想在手机上看，唯一支持的办法是用 [Tailscale](https://tailscale.com/) 做一层私有反代——你的数据仍然只在你自己的设备之间流动，不上公网。

**先说清楚：这条路径作者还没有在真实设备上完整验收过**（见《[已知问题](已知问题.md)》）。愿意折腾再往下看。

第一步，在电脑上开反代。把下面这行粘到终端里，回车：

```bash
tailscale serve --bg 59418
```

第二步，把 Tailscale 给你的那个 `.ts.net` 主机名，写进配置文件 `server/runtime/config.json` 里的 `allowedHosts` 列表。**不写进去会被服务端直接拒绝**——这是服务端的安全边界，不是 bug。

第三步，手机上访问 `https://你的主机名.ts.net/dashboard/`，重新输入一次访问密钥。

**绝对不要开 Tailscale Funnel。** 那会把你的两本账本暴露到公网上。
